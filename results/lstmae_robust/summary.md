## 关键量化：同一批 run 上两把尺子的摆幅

- **F1（现有协议）**：0.2827 ~ 0.7411，极差 **0.4584**（2.62×）
- **AUROC（好尺子）**：0.5754 ~ 0.6051，极差 **0.0297**
- base rate（异常窗占比）= 0.1388；AUROC=0.5 为随机
- **AUROC 全程 > 0.5**（最低 0.5754）⇒ LSTM-AE 的分数**有信息**，不是噪声（对照：SECOND 在 MSL 上 AUROC=0.4975）

- ⇒ **F1 的摆幅（0.458）远大于 AUROC 的摆幅（0.030）**，而两者测的是同一批模型 → F1 的波动来自**协议**（oracle 阈值 + point-adjust），不来自模型质量

> 注：F1 用的是 `bf_search` 在 test 上搜出的**最优**阈值（oracle），且 `adjust_predicts` 会把命中段的整段判正。这两件事叠加使 F1 对分数分布的形状极敏感、对排序质量却不敏感。
> 注：LSTM-AE 无 dropout，分数可复现；本表与 `main.py` 的 F1 同源（同一 ckpt、同一批窗）。
