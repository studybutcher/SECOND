# PESR vs LSTM-AE 显著性检验（完整 test，47,854 窗口，n=3）

配对单位 = seed；同一 seed 下两模型共享训练噪声实现与 test 窗口（`set_seed → get_data → add_noise → build_model`）。

效应量 dz = mean(Δ)/sd(Δ)（配对）。Holm 校正在每个比较族内对 6 个 η 做。n=3 时 p 值依赖正态假设，非参数检验最小 p=0.25，因此同时看效应量与 Δ 的 95% CI。

**p 与 CI 的对偶关系**：双侧 α=0.05 下，`raw p < 0.05` ⟺ 0 不在**单项** 95% CI 内（同一个 t 统计量）。Holm p 是校正后的，不能配单项 CI；表中另给 `Bonferroni 95% CI（m=6）` 作为同时区间。Bonferroni 比 Holm step-down 更保守，两者不严格对偶。跨 η 平均是单次检验，单项 CI 即可。

> 解读限制：
> 1. n=3 的 p 值只说明“在正态 + 配对差正态假设下”，不能替代效应量；Δ 的 CI 是更稳的表述。
> 2. 6 个 η 不是独立样本，不能把 18 个 run 当 n=18 做检验（伪重复）。跨 η 汇总只做 seed 级平均后的 n=3 检验。
> 3. 若审稿要求非参数或更稳的 p，需要把 seed 加到 ≥6（符号检验/Wilcoxon 在 n=6 才能到双侧 0.031）。
> 4. 若要做窗口级检验，需要保存逐窗口分数并在时间块上做block bootstrap（point-adjust 使窗口不独立）。当前未落盘。
> 5. `p ≥ 0.05` 只表示“没有足够证据拒绝”，不等于两模型相同；要主张等价需 TOST + 预设 margin。`p < 0.05` 也不表示差异大，应同时看 Δ 的 CI 与效应量。
> 6. 建议主比较只保留两条：`PESR bf − LSTM bf` 与 `PESR POT① − LSTM POT③` 的跨 η 平均（0–0.2），各一次检验；逐 η 表作为探索性/敏感性分析，报 raw p + 单项 CI。
