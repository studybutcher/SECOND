### 0.3 DTAAD 论文与其公开代码的 POT 参数不一致

论文原文存于 `docs/refs/DTAAD_2302.10753.pdf`（附录 A）：

> "For POT parameters, **q = 10⁻⁴ for all data sets, low quantile is 0.07 for SMAP, 0.01 for MSL, and 0.001 for others.**"

方法节还有一句定性描述：

> "Here are two parameters (thr) and (q) that **can be set based on experience**: low quantile (e.g., less than 7%) and q (10⁻⁴)"

**逐项比对论文与公开代码：**

| 参数 | 论文 | 公开代码 | 差异 |
|---|---|---|---|
| `q` | **1e-4**（全数据集统一） | **1e-5**（`pot_eval` 默认值，[pot.py:119](../DTAAD-main/src/pot.py) 调用时未传） | **10×** |
| "low quantile" | 0.07 / 0.01 / 0.001 | `level` = 0.98 / 0.999 / 0.993 / 0.999 | 数值与语义**均不符**（论文称"低位分位"，SPOT 的 `initialize(level)` 是高位分位） |
| `scale` | **未披露** | 1.04 / 1.06 / **1.5**（MSL 的 `C-2_`/`T-4_`） | 论文**零披露** |

三点结论：

1. **论文自认是"凭经验设置"**（"set based on experience"）——作者本人未给出推导、验证集或搜索过程。这直接支持本工作自主标定的正当性：**且本工作比它更保守**（逐数据集 vs 逐子序列）。
2. **"对齐 DTAAD"存在歧义，必须定一边**：本 PRD 决定 **对齐公开代码**（可复现、可验证；审稿人核对时跑的是代码），并在文中说明论文与代码的 POT 参数不一致。
3. **`q` 的不一致对主口径无实质影响**：实测 `pot_dtaad` 阈值随 `q` 仅变动 **0.11%**（166.12 → 166.29，`q` 从 1e-2 到 1e-8）。但 `pot_evt` / `pot_dynamic` 对 `q` **极敏感**：

   | q | pot_evt | pot_dynamic |
   |---|---|---|
   | 1e-4（论文） | 179.47 | 179.25 |
   | 1e-5（代码） | 185.27 | 184.97 |

   而 WADI 测试分数最高仅 178.48 → 两个口径的阈值都**跑出数据范围**，F1 必然归零。**故附列的 `q` 必须固定并写明**，否则该列数字不可复现。

## 1. 与 DTAAD 的对齐清单

**原则：凡属「评测协议」的环节必须逐行对齐；凡属「模型自身」的环节本就不同，不需也无法统一。**

| 环节 | DTAAD | 本仓库 | 状态 |
|---|---|---|---|
| `spot.py`（SPOT 库） | — | — | ✅ **逐字节相同**（已 diff） |
| 阈值规则 | `mean(run(dynamic=False)['thresholds']) * lm[1]` | 同 | ✅ 一致 |
| point-adjust 循环体 | `pot.py:53-74` | `eval_method.py:56-73` | ✅ **逐行相同**（仅注释不同） |
| `q` | `pot_eval` 默认 `1e-5` | `DTAAD_Q = 1e-5` | ✅ 一致 |
| `dynamic` | `False` | `False`（主口径） | ✅ 一致 |
| 拟合失败重试 | `while True: except: lms *= 0.999` | 同，但有界（1000 次后回退并记 `fit_ok=False`） | ✅ 等价（本次 4 格 `fit_ok` 全 `True`） |
| **`init_score` 来源** | **全训练集** | **全训练集** ← 本版修正 | ✅ 一致（代码已改，**待重跑**） |
| **阈值超参 `(level, scale)`** | `lm_d` 表（逐子序列手调） | **自主标定** | 🔶 **自主**（见 §3） |
| **评测粒度** | **单个子序列**（`P-1_` / `C-1_`） | **全数据集** | ⚠️ **不同**（见 §2） |
| `model.eval()` | 调用（分数确定） | 不调用（dropout 开，分数随机） | ❌ 不同（本版保留，§6.2） |
| 模型结构 / 训练流程 | TCN-attention，`lr_d` 表 | VAE+Mamba，Adam lr=0.01 | ❌ **本质不同，不需统一** |
| `bf_search` 实现 | `start..end` 网格 | 百分位 93→100 | ❌ 不同（两者都是 oracle，不影响 POT 列） |

### 1.1 论文里可以直接使用的表述

> 阈值选择环节**完整复用 DTAAD 的实现**：同一份 SPOT 库、同一套阈值规则（`mean(run(dynamic=False)['thresholds']) × scale`）、同一套 point-adjust 逻辑、`init_score` 同样取自训练集分数、`q = 1e-5`。差异仅在于 **`(level, scale)` 的取值**——DTAAD 的 `lm_d` 是在其自身模型的分数分布上标定的，直接迁移会使本模型 F1 归零（MSL：0.9408 → 0.0000），故本工作为本模型重新标定。

**不得写**："我们实现了 POT / EVT 阈值选择" —— 该规则实测退化为「训练分数的 `level` 分位数 × scale」（PRD3 §2.1.1，本轮复验：SMAP 27.0303 vs 27.0296 逐位吻合）。

## 2. 评测粒度（**已定：必须对齐** ｜ G2）

### 2.1 问题

`DTAAD-main/main.py:36-37` 硬编码只加载一个子序列：

```python
if dataset == 'SMAP': file = 'P-1_' + file     # 只读 P-1_train.npy
if dataset == 'MSL':  file = 'C-1_' + file     # 只读 C-1_train.npy
```

佐证：`src/params.json` 逐子序列给 `(level, scale)`（SMAP 有 `P-1_`、`A-4_`；MSL 有 `C-1_`、`C-2_`、`T-4_`）；`constants.py` 的值恰等于所加载子序列的值；README 示例的 SMAP 总数 8505 也正好是单子序列量级。

而本仓库在**全数据集**上评测（SMAP = 277952 个窗口）。

> **两篇论文里的 "SMAP" 不是同一个东西。** 既然目标是并排比较（G2），必须对齐——否则数字放在一起没有意义。

**参照量级**（DTAAD 论文 Table 7）：

| | SMAP | MSL | SWaT | WADI |
|---|---|---|---|---|
| DTAAD F1\* | 0.8985 | 0.9212 | 0.8088 | **0.0977** |

### 2.2 对齐方案：**离线切片，不必重跑模型**

关键观察：**模型的前向是同一批数据**，粒度差异只体现在「分数与标签如何分组算 F1」。因此：

1. 用现有流程跑出**全数据集**的 `test_score` / `test_label`（Phase 0 已产出）
2. 还原**子序列边界**
3. 按 DTAAD 的口径（单序列 `P-1_` / `C-1_`，或全部子序列）切片算 F1

**成本：零 GPU** —— 与 Phase 0 共用同一批产出。

**边界窗口的近似**：本仓库的滑窗建在**拼接后**的数组上，所以子序列交界处约 `W` 个窗口横跨两段。二选一，须在文中注明：

| 方案 | 做法 | 影响 |
|---|---|---|
| **丢弃边界窗口** | 每段丢掉首尾各 `W-1` 个窗口 | 最干净；SMAP 55 段 × 70 ≈ 损失 1.4% 窗口 |
| 保留 | 按窗口中心归属 | 损失更少，但边界窗口含跨段数据 |

### 2.3 ✅ 已解决：子序列边界（2026-09-23）

**重建方式**（`bench/subseries_index.py`，逐行验证通过）：

> 拼接数组 = 属于该数据集的子序列**按文件名排序**拼接，**各自排除一个文件**：
> - SMAP：54 个 25 维文件，排除 **`P-2.npy`** → 427617 行
> - MSL：28 个 55 维文件，排除 **`T-10.npy`** → 73729 行

判定依据：文件行数与「排序拼接总长 − 目标长度」的**差额恰好相等**（SMAP 差 8209 = `P-2` 长度；MSL 差 670 = `T-10` 长度），去掉后**逐行严格比对 max|Δ| = 0**。

> 为什么能逐值比对：`utils.preprocess()` 用 `MinMaxScaler`，是**逐列仿射变换**，故各自归一化到 [0,1] 后应完全一致。

**关键位置**：`P-1` = `[354374, 362879)`（长 8505）｜`C-1` = `[0, 2264)`（长 2264）

**交叉验证**：`P-1` 长度 8505 与 DTAAD README 示例的 `TP=748 + FP=167 + TN=7590 + FN=0 = 8505` 完全吻合。

**⚠️ 一个必须知道的后果**：评测范围被 val 截断为 `[0, L−⌊0.35L⌋)`，而拼接按文件名排序（`A→…→P`），因此

| 数据集 | 评测范围 | `P-1` / `C-1` |
|---|---|---|
| SMAP | [0, 277952) | `P-1` 在 354374 → **超出范围，需单独补前向**（8435 窗口，约 10 秒） |
| MSL | [0, 47924) | `C-1` 在 0 → **在范围内，可离线切片** |

**结果** → [与DTAAD对比_子序列粒度.md](与DTAAD对比_子序列粒度.md)

## 3. 超参 `(level, scale)` 的自主标定

### 3.1 允许自主的范围

| 量 | 是否自主 | 说明 |
|---|---|---|
| `q` | ❌ 固定 `1e-5` | 对齐 DTAAD 公开代码。实测它对主口径 `pot_dtaad` 仅影响 **0.11%**（166.12→166.29），无标定价值；但对 `pot_evt`/`pot_dynamic` 影响极大（§0.3），故附列必须固定同一 `q` 并写明 |
| `dynamic` | ❌ 固定 `False` | 对齐 DTAAD（`dynamic=True` 作附列） |
| `init_score` 来源 | ❌ 固定「全训练集」 | 对齐 DTAAD |
| **`(level, scale)`** | ✅ **自主** | 本 PRD 的标定对象 |
| 是否 per-dataset | ✅ 自主 | DTAAD 是 per-子序列；我们至少 per-dataset |

> ⚠️ **可比性约束的是 procedure，不是取值。** 见 §3.1.1。

### 3.1.1 ⚠️ 可比性的真正约束：两库必须同 procedure

**改变 `(q, level, scale)` 的取值本身不影响可比性，改变「选择这些值的做法」才影响。** 因此：

| 组合 | 可比？ |
|---|---|
| SECOND 与 MUTANT **都**用固定 `(0.98, 1.0)` | ✅ |
| SECOND 与 MUTANT **都**逐数据集标定 | ✅ |
| SECOND 与 MUTANT **都**用同一份标定网格、同一准则 | ✅ |
| **SECOND 标定、MUTANT 不标定（或反之）** | ❌ **不可比** |
| 两库用**不同的标定准则**（一个取 test 最优、一个取 val 最优） | ❌ **不可比** |

**硬性要求**：本 PRD 的标定流程，**两个仓库必须逐字节共用同一份实现与同一套准则**（与 §5-验收-3「两库 `pot_eval` 逐字节相同」同性质）。产出的 `(level, scale)` 表**可以不同**（因为两库的分数分布不同），但**产生这张表的程序必须相同**。

> 与 DTAAD 的对比不受本条约束：DTAAD 的数字是已发表、固定的，其 `(q, level)` 取值不影响「我们的数字能否与其并列」。真正影响与 DTAAD 可比性的是**评测粒度 / point-adjust / eval 模式**（见 §2、§6）。

**为什么自主是合理的**：DTAAD 自己的表就是**手工逐子序列调出来的常量**（`params.json` 里 SMAP `P-1_`=(0.98,1)、`A-4_`=(0.991,1.06)；MSL `C-1_`=(0.999,1.04)、`C-2_`=(0.9999,1.5)）。同一数据集内不同子序列取值不同，只可能来自逐项调参。**我们为本模型做同样的事，方法上与该基线同性质。**

### 3.2 ⚠️ 标定准则的诚实性约束

标定需要一个带标签的集合。三个候选：

| 集合 | 可用性 | 结论 |
|---|---|---|
| 训练集 | 无标签（`get_data` 返回 `(train_data, None)`） | 只能定 `level` 的分位位置，**无法定 scale** |
| 验证集 | ⚠️ **val ⊂ test**（发现 H，占 test 的 53.8%） | **等价于用测试集**，不构成干净退路 |
| 测试集 | 有标签 | 直接泄漏 |

**结论：不存在干净的带标签标定集。** 因此必须在论文里**明确披露**标定的选择准则。三种可接受的写法：

| 口径 | 主表位置 | 声明写法 | 强度 |
|---|---|---|---|
| **① label-free 固定参数** | **主表** | "全数据集统一 $(\text{level},\text{scale})=(0.98, 1.0)$，无任何调参" | 最强，无争议 |
| **② 逐数据集标定表** | 对照列 | "逐数据集选择，与 DTAAD 的 `lm_d` 同性质" | 中，需披露 |
| ③ 混合 | ❌ 不用 | 会同时失去两边的可辩护性 | — |

> **推荐：① 作主口径、② 作对照列，两列并列。**

理由：① 已能满足需求——在 `init_score` 取 20000 窗口的旧口径下，① 相对 oracle 只掉 SMAP 0.0239 / MSL 0.0070 / SWaT 0.0320（**WADI 除外，见 §5**）。三格掉分都在 3 个百分点内，**不需要靠调参来找回**。而 ② 的价值是被问到「你们是不是也在测试集上调参」时，拿得出 ① 的数。

### 3.3 标定做法（当 ② 需要时）

**网格**（比 PRD3 §2.3 更细——实测 WADI 的可用带极窄，粗网格会漏掉）：

```
level ∈ {0.95, 0.96, 0.97, 0.98, 0.985, 0.99, 0.9925, 0.995, 0.997, 0.998, 0.999, 0.9995}
scale ∈ {0.98, 1.00, 1.02, 1.04, 1.06, 1.08, 1.10}
```

**成本为零**：`pot_dtaad` 的阈值 ≡ `quantile(init_score, level) × scale`（PRD3 §2.1.1），因此标定**只需缓存一次分数，之后是纯 numpy 扫描**，不占 GPU。

**必须同时产出「阈值响应曲线」**：F1 关于绝对阈值的曲线，以及 F1≥0.90 / ≥0.94 / ≥0.95 三个 plateau 的宽度。**只报网格 argmax 是不够的**——WADI 的可用带只占分数全长 2.3%，网格点之间可能整段错过，且 argmax 会掩盖「这个数到底有多脆弱」。

**产出记录**（每格）：`(level, scale)`、绝对阈值、F1/P/R、plateau 宽度、该 `level` 对应训练集上多少个样本。

## 5. WADI 单列讨论

WADI 这一格不能与其余三格并列解读，必须在论文里单独说明：

| 事实 | 数值 |
|---|---|
| 测试集异常段数 | **1**（长度 175） |
| point-adjust 后果 | 命中 1 个点即 R=1.0；**1/175 的点被命中即可拿满分召回** |
| oracle 阈值下逐点 F1 | **0.0103**（point-adjust 后 0.9511，放大 92×） |
| oracle 阈值下阈值之上的点 | 异常点 **1** 个 / 正常点 **18** 个 |
| 异常点分数分布 | 中位数 150.87 **低于**正常点中位数 151.28；最高 171.57 < 正常点最高 178.48 |
| 可用带 | F1≥0.90 仅占分数全长 **2.3%**；F1≥0.95 的 `level` 窗口宽 **0** |
| **DTAAD 自身在 WADI 上的 F1** | **0.5455**（论文 Table 3，全量训练；P=0.9017、**R=0.3910**、AUC=0.6950） |

> ⚠️ **勘误（2026-09-23）**：本节此前写的 **0.0977 是错的**。0.0977 出自论文 Table 7 / Table 4 的 **`F1*`**，而论文明确定义 *"The AUC\* and F1\* represent the AUC with **20%** [of] the training dataset"* —— 那是**少样本变体**，不是主结果。主结果在 **Table 3**：SMAP 0.9023 / MSL 0.9495 / SWaT 0.8101 / WADI 0.5455。

**必须同时注意性质不同**：DTAAD 在 WADI 上**召回只有 0.3910**（漏检 61%），它是**模型漏检**，不是"指标退化"。而 SECOND 的 WADI 是召回恒为 1.0、由 precision 决定一切（point-adjust + 单异常段）。**两者是不同性质的问题，不能互相佐证。**

**建议写法**：把 WADI 标注为「该切分下 point-adjust 主导，指标不反映逐点检测能力」，并**补一列逐点 F1**（不加 point-adjust）作为对照；同时引用 DTAAD 自身在 WADI 上的 0.0977 作为旁证。这比强行报一个 0.95 更有说服力。

## 6. 保留不同（本版不处理，但须声明）

### 6.1 模型结构

DTAAD 是 TCN-attention，本工作是 VAE+Mamba。**这是两篇论文的差异，不是协议差异**，不需要统一，也不需要声明。

### 6.2 Dropout（发现 I，2026-09-23 更新）

推理未调 `model.eval()`，`nn.Dropout(0.1)` 激活。**实测（详见 [阈值选择结果 v2](阈值选择结果_对齐DTAAD.md) §7a）：**

| | 结论 |
|---|---|
| **可复现性** | ✅ **固定 seed 时逐位可复现**（seed=42 两次运行 `max|Δ| = 0`）。历史漂移来自不同运行的 RNG 状态，**不是推理随机**。之前的「不可复现」说法已修正 |
| **eval 模式** | ❌ **模型塌缩**——对所有输入输出同一隐表示，分数退化为常数（SMAP std 2.3e-06 / 8 个唯一值；MSL 1.2e-05 / 9 个唯一值），**判别力为零** |
| **train vs eval 的唯一差异** | dropout（模型无 BatchNorm；LayerNorm/RMSNorm 两模式行为相同） |

> **关键推论**：dropout 不是"给好信号加噪声"，**它本身就是信号源**。故**不能靠关掉 dropout 获得确定性模型**——必须重训（训练时即不使用 dropout）。

**本版决定：保留现状 + 在论文中声明「固定随机种子下可复现」。**
重训无 dropout 版本列为可选（§7-Q12）。
