## 1. 三个关键判断（r3 的实质内容）

### 1.1 污染源改用结构化异常注入，且原封存理由不再适用

**原封存理由**（`docs/PRD4text_状态记录_20261007.md` §3.1）：α **无法按可检出性标定** ——
"调 α 使 clean 模型对注入段 ≥90% 检出"不可满足，α 放大到 1000σ 检出率仍饱和在 **47.5%**。

**为什么现在不成立**：那个标定目标是**为检测型指标服务的**。本版主指标是
**固定正常验证集的 MSE**，不涉及检出率 ⇒ **α 只是一个固定的、被记录的扰动幅度**
（`gen_contam` 默认 `α=1.5`，口径 = 该通道在模型输入空间的 σ 倍数）。结论写成
"**在 α=1.5σ 的结构化注入协议下**"即可。

**为什么不改回真实 donor**：额度硬上限。真实异常只能从 test 攻击段取：

| 数据集 | 训练窗 | test 异常点 | ρ=10% 需要 | ρ=20% 需要 |
|---|---|---|---|---|
| SWaT | 494,965 | 54,621 | 90.6% 异常池 | **181%** ❌ |
| MSL | 58,247 | 7,766 | 75.0% 异常池 | **150%** ❌ |

ρ=20% 数学不可能；ρ=10% 会把评测集掏空。**故本版不用真实 donor。**

**必须保留的限定**：结构化注入是**合成异常段**，不是真实工业攻击 ⇒
只能支撑 "**locally corrupted / anomaly-like observations** 干扰正常模式学习"，
**不能**写成 R1 原话的 "anomalous observations"。

### 1.2 MPA 的判据要锋利：$E_A$ 必需 + 容量对照

$G_{\mathrm{MPA}}>0$ **不能单独当结论** —— MPA 引入了参数，可能只是"整体更强的自编码器"。
把 $E_A$（固定异常探针 MSE）升为**必需**，才能区分两件事：

| 观测 | 才能写的结论 |
|---|---|
| $G_{\mathrm{MPA}}>0$ **且** $E_N$ 的相对改善 **>** $E_A$ 的相对改善 | MPA 改善的是**正常模式建模** |
| $G_{\mathrm{MPA}}>0$ 但 $E_N$ / $E_A$ **等比例**改善 | 只能说"该骨干**重建能力整体变强**"，**不能**说更懂正常模式 |
| $G_{\mathrm{MPA}}\le 0$ | 未验证到 MPA 的重建增益 |

形式化（按 seed 配对，先配对再平均）：

$$G_{\mathrm{MPA}}^{(N)}=\frac{E_N(\mathrm{AE})-E_N(\mathrm{MPA{+}AE})}{E_N(\mathrm{AE})},\qquad
G_{\mathrm{MPA}}^{(A)}=\frac{E_A(\mathrm{AE})-E_A(\mathrm{MPA{+}AE})}{E_A(\mathrm{AE})}$$

**判据**：$G^{(N)}>0$ 且 $G^{(N)}-G^{(A)}>0$（附 seed 间 std）。

**可选但强烈建议的容量对照**：给纯 AE 的首层加宽到参数量与 MPA 相当，
看 $G^{(N)}$ 是否消失。**一句话答不上"不就是多了参数吗"会很被动。**

### 1.3 主干：AE 为主，VAE 为次，LSTM-AE 不进主实验

换掉 LSTM-AE **不只是"更简单"**：

1. **v1 卡死的那一点自动消失。** MPA 的输出是 `[B, C, 512]`（`Model.py:206-227`
   把 `patchnum×latent` 用 `projection1/2` 压掉了，**没有时间轴**），喂不了 LSTM；
   而 MLP-AE 吃展平窗口，MPA 输出**池化或展平即可接**，不需要时间语义。
2. **瓶颈是真瓶颈。** MSL 展平 `70×55=3850` → latent 256 ⇒ **15× 压缩**；
   对比 SECOND 的 `275/256 ≈ 1.07`（伪瓶颈，是塌缩的温床）。
3. **LSTM-AE 会引入混淆**：MPA 的作用本身就是时序分块，两者纠缠后无法归因。

**代价**：外部效度弱（toy 骨干）。**补法**：加 **VAE 第二主干**（比 AE 更贴近 PESR 的
CRR 头），VAE 用 **reconstruction mean** 算 MSE 以避开采样噪声。两个主干 ≫ 一个，成本近乎不变。

## 2. 目标与论证边界

### 实验 A｜问题是否存在（Motivation）

同一 AE，对比 clean 与注入训练，看固定正常验证集 $E_N$ 是否改变。

$$\Delta E_N(\rho)=\frac{E_N(\mathrm{AE},\rho)-E_N(\mathrm{AE},0)}{E_N(\mathrm{AE},0)+\varepsilon}$$

$>0$ 变差；$\approx0$ 未观察到；$<0$ 不得写成"污染损害了学习"。

### 实验 B｜MPA 是否有重建增益（Module validation）

AE vs MPA+AE，**同一个原始输入重建目标**：

$$X\xrightarrow{\rm AE}\hat X,\qquad X\xrightarrow{\rm MPA}\xrightarrow{\rm Adapter}\xrightarrow{\rm AE}\hat X$$

**成功条件**（v2 已收窄，保留）：只要求**固定正常验证集 MSE 更低**，
**不要求**污染斜率更平、不要求 AUPRC 更高、不要求 $E_A$ 更大。

**证据边界（写进正文）**：仅支持"MPA 可改善该 AE 框架的正常模式建模"；
**不能**宣称"MPA 抑制了异常模式学习"或"PESR 的污染鲁棒性得到证明"（v2 §1 已写，保留）。

## 3. 污染协议

### 3.1 结构化异常段注入（`bench/gen_contam.py` 协议）

- **ρ ∈ {0%, 5%, 10%, 20%}%**，定义 = **被替换的原始训练行占比**（替换而非增补，总长不变）
- **嵌套前缀**：`A_5% ⊂ A_10% ⊂ A_20%` 已由生成器构造性保证（`plan[ρ]` 是 `plan[ρ_max]` 的长度前缀）
- **α = 1.5σ 固定**（逐通道 σ，在模型输入空间）
- 段只落在**可注入通道**、只落在连续变量上；不违反离散/指示列
- 所有配置共享**同一组**段位置与同一个 scaler（只从 clean train 拟合一次）
- 同时报 **$\rho_{win}$**（窗口级污染率，≠ ρ）

### 3.2 ⚠️ 数据集支持的现状（必须先解决）

`bench/gen_contam.py` **目前只支持 MSL / SMAP**：`place_all` 依赖
`stacked_blocks` 的 `injectable / t_start / t_end`（stacked 布局专有），
且 `--lbar-typ 583` 是 MSL 推出来的。

| 数据集 | 现状 | 要做的 |
|---|---|---|
| **MSL** | ✅ 生成器已验证（12 组全过四项断言） | 无 |
| **SWaT** | ❌ | ① flat 布局的 block（整条序列一块）② 只注入连续通道（`bench/channel_split.py` 已能给出 SWaT 的连续/离散划分）③ **重新推段长计划**（docstring 自记"r2 的段数公式在 SWaT 上自相矛盾"） |

**顺序建议：MSL 先跑（零新代码）→ SWaT 再扩。**
（另一条考虑：SWaT 的 AE 输入更干净 —— `[35,51]` 全是连续通道；
MSL 是 `[70,55]` = 1 个信号列 + 54 个二值指示列。若在乎输入干净度，把 SWaT 的扩展提前。）

### 3.3 敏感性：Gaussian 噪声（不混入主曲线）

沿用 v2 §2 一级的生成式 $x'=x+\alpha\sigma_j\epsilon$（**按通道 σ 缩放**，只加连续通道），
α=1 固定。**单独命名、单独解释**，**不与结构化注入混进同一张 ρ 曲线**
（两者 ρ 的定义不是同一个统计量，v2 §2 已写明）。

> ⚠️ **不要用仓里现成的 `add_noise`**：它在 `preprocess` 之后按**绝对常数 ±2/±5** 替换整行，
> 而数据已归一化到 [0,1] ⇒ 等于替换成范围外的垃圾，且 55 通道共用同一幅度（状态记录 §6 已点名）。
> 要用就新写 `add_noise_sigma`，不动旧的。

## 4. 数据协议

1. 从正常数据划 `train_normal` 与**固定** `val_normal`，时间段互不重叠，跨边界留一个窗口的隔离区；
2. scaler **只在 `train_normal` 上拟合**，所有条件复用；
3. **窗口化在注入之后**（与 clean setting 完全相同的 windowing）；
4. `normal_probe` / `anomaly_probe` **只用于评价与作图**，不参与梯度更新与模型选择；
5. 主表用**统一的固定训练轮数**；正常验证 loss 只作监测，不针对不同模型采取不一致的选择策略；
6. 推理统一 `model.eval()` + 确定性 forward（**禁止依赖 dropout 的随机输出**）；
7. **检查正常验证集的输入与目标都是 clean 原始数据**，不能拿有噪输入当"正常质量"标准（v2 §3.7，保留）。

## 5. 模型

### 5.1 主干 AE（主）

$$\mathrm{flatten}(X)\to \mathrm{Enc}\to z\ (\text{latent }256)\to \mathrm{Dec}\to \hat X,\qquad
\mathcal L_{\mathrm{rec}}=\tfrac{1}{TC}\|X-\hat X\|_F^2$$

- 2–3 层轻量 MLP；**瓶颈必须真**（MSL: 3850→256 ≈ 15×）
- hidden / latent **先固定并记录**，**不得**依据 test label 反复调参
- 超参（v2 未给，r3 先钉默认，可改）：
  `hidden=[1024,512]`、`latent=256`、`Adam lr=1e-3`、`bs=128`、`epochs=50`、`seed∈{42,7,17}`

### 5.2 主干 VAE（次，可选）

同结构 + KL 项；**$E_N$ 用 reconstruction mean 计算**（不用采样，避免把 VAE 采样噪声算进 MSE）。
报告 $\beta$ 或 KL 权重。

### 5.3 MPA+AE

$$X\xrightarrow{\rm MPA}H\xrightarrow{\rm Adapter}H'\xrightarrow{\rm AE\ Encoder}\to\hat X$$

**接入方式（r3 明确，v1/v2 没给）**：MPA 输出 `[B, C, 512]` **没有时间轴**，
对 MLP-AE 只需 **在通道维池化 → `[B, 512]`**（或展平 `[B, C·512]`）再进 adapter。
**不需要**任何"时间步"语义 —— 这正是换 MLP-AE 换来的好处（§1.3）。

**要求**：

- 复用论文 MPA 的 **patching + 多视角 embedding + 对齐思路**，**不引入 MSSA / CRR / 新专用模块**
- 只加**最小维度适配层**，记录其结构与参数量
- **重建目标始终是原始 $X$**，不能让 MPA+AE 去重建 MPA 自己的输出
- 两模型使用**相同的 AE encoder/decoder 结构定义与 latent 大小**，分别独立训练
- 若保留一致性损失：$\mathcal L=\mathcal L_{\mathrm{rec}}+\lambda L_a$，固定并记录 $\lambda$，
  结论只能归于**完整 MPA（多视角提取 + 一致性约束）的联合效果**
- 报告两模型**参数量**及 adapter 结构（v2 §4.2，保留）

## 7. Gate（全过才铺 3 seeds）

| Gate | 检查 | 判据 |
|---|---|---|
| **A** | 注入生效且未破坏标签 | 非污染行逐位不变；指示列逐位未动；嵌套 $\rho$ 前缀成立（沿用 `gen_contam` 的四项断言） |
| **B** | 划分无泄漏 | train/val/test 时间段互不重叠；scaler 只从 train 拟合 |
| **D** | 逆过程正确 | 对 ρ=0 的生成物做 `np.array_equal(clean)` |
| **M** | MPA 接入正确 | 重建目标是原始 $X$；adapter 只改维度；shape 断言通过 |
| **V** | 瓶颈有效 | latent ≪ 输入维（如 256 vs 3850），且**不是**恒等映射（v2 §4.1） |
| **N** | **重建分数/表示非常量** | 同一批真实 / 全零 / 随机输入下，$\hat X$ 的逐元素 std > 取值量级的 1e-3 |

> v2 里没有这一项，r3 补上。

## 9. 判据（预注册）

| # | 观察 | 结论 |
|---|---|---|
| **D1** | 随 ρ 上升 $E_N$ 单调上升 | 正常模式重建质量受可测量的注入影响 |
| **D2** | 随 ρ 上升 $E_N$ 不变 | 本协议下未检测到影响；**不得**声称已定量证明 |
| **D3** | $E_N$ 随 ρ **下降** | 可能正则化；**不得**写成污染有害 |
| **D4** | $G^{(N)}>0$ 且 $G^{(N)}-G^{(A)}>0$ | MPA 改善**正常模式建模** |
| **D5** | $G^{(N)}>0$ 但两者等比例 | MPA 使该骨干**重建能力整体变强**（不涉及"更懂正常模式"） |
| **D6** | $G^{(N)}\le 0$ | 未验证到 MPA 重建增益 |
| **D7** | 容量对照下 $G^{(N)}$ 消失 | MPA 的增益可由容量解释 ⇒ 结论必须限定为"含容量的联合效果" |
| **D8** | $E_N$ 与 $E_A$ 结论冲突 | 两者都报，**不得**只报支持叙事的那一个 |

**禁止**：不出现期望曲线就调大 α 或 ρ（v2 §2 已写，保留）；只报部分 ρ 档；
用某次有利 seed 当普遍效果。

## 10. 能写 / 不能写

| 观察 | 可以写 | 不能写 |
|---|---|---|
| 注入后 $E_N$ 上升 | 该 AE 的正常重建受**结构化注入**干扰 | 真实工业攻击必然有相同影响 |
| $G^{(N)}>0$ | MPA 在该 AE 框架中改善正常模式重建 | MPA 已证明可消除异常污染 |
| clean 更好但污染退化一样 | MPA 有干净数据重建收益 | MPA 有更强污染鲁棒性 |
| 两者无稳定差异 | 当前实验未验证 MPA 的重建增益 | 拿某次有利 seed 当普遍效果 |

**统一原则（v2 §9 保留）**：不能把"正常重建更好"自动等同于"异常检测更好" ——
重构类检测中，**异常也被很好地重构时反而降低判别力**。
