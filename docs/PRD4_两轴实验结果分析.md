# PRD4 · 两条扰动轴的结果分析（噪声 / 异常）

> 记录日期：2026-10-07。本文汇总**两条扰动轴**已跑出的全部结果，并说明为什么两条
> 都测不出"消融导致劣化"。所有数字均取自 `results/` 与 `nohp-out/`，可逐条复核。
>
> 相关：`docs/PRD4text_状态记录_20261007.md`（异常轴的资产封存）、
> `docs/PRD4_噪声定量实验.md`（噪声轴的 PRD）、`docs/定量分析_WADI基线诊断.md`。

## 0. 结论速览

| | 噪声轴 | 异常轴 |
|---|---|---|
| 扰动 | 按比例把训练时间戳替换成噪声 | 往训练集注入连续异常段 |
| 施加位置 | **只在训练侧**（`main.py:222`） | **只在训练侧**（`main.py:203`） |
| 测试侧 | **干净** | **干净** |
| 最强档下的结果 | **无退化**（SMAP/SWaT 甚至略升） | **无退化**（净 Δ = −0.0012） |
| 能否支撑"消融→劣化" | ❌ | ❌ |

**两条轴都测不出劣化，且原因不同、可分别定位**（见 §4）。

## 1. 两条轴的协议对照

| | 噪声轴（`script/robust`） | 异常轴（PRD4text） |
|---|---|---|
| 扰动定义 | `η` = 被替换的时间戳比例；噪声为 `uniform(-2,2)` / `spike(±5)` / `random_walk` 三选一 | `ρ` = 被污染的时间戳比例；注入连续异常段（level shift / amplitude scaling / perturbation），强度 `ασ` |
| 施加对象 | `train_data = add_noise(train_data, η)` | `train_data = np.load(contam.npy)` |
| 测试/验证 | **干净** | **干净** |
| 时间结构 | 无（随机独立时间戳） | 有（连续段，段长 ~583 s） |
| 已跑数据集 | SMAP, SWaT, WADI, MSL | WADI, MSL |
| 运行脚本 | `script/robust/*.sh` | `script/contam/*.sh` |

**共同点（关键）**：两者都只动**训练集**，测试集全程干净。因此两者测的都是
「**用被扰动的数据训练，还能不能学出一个好模型**」，而**不是**「模型在扰动输入下的检测能力」。
后者才是"抗扰"的通常语义。

从 `nohp-out/Robust/*.out` 解析。这些 run **只在日志里**（robust 脚本原先不写结果 JSON）。

| F1 | 0.9761 | 0.9749 | 0.9697 | 0.9771 | **0.9798** |

**单调性：无。把 50% 的时间戳整行替换成噪声，F1 没有下降，末档还最高。**

|---|---|---|---|---|---|
| F1 | 0.9821 | 0.9831 | 0.9783 | 0.9878 | **0.9850** |

**单调性：无。同样是平的，甚至略升。**

### WADI（W=70, bs=24）

| η | n | F1 范围 |
|---|---|---|
| 0.10 | 5 | 0.7337 ~ 0.9914 |
| 0.50 | 5 | 0.6769 ~ 0.9459 |

被方差淹没（同设定跨 run 跨度 0.25+），**无单调关系**。

### MSL

那批日志未打印 `noise` 行，只有 3 个值：`0.9436 / 0.9648 / 0.9459`（W=70, bs=60）。
**无噪声档信息，不可用。**

### 3.2 MSL ρ=0%（seed 42, W=70, bs=60）—— 唯一配对的一组

|---|---|---|---|---|

**`nomssa`（α=1.5）**

| ρ | F1 |
|---|---|
| 0%（seed7） | 0.9334 |
| 20% | 0.9490 |

**+0.0156 —— 方向与假设 2 相反（污染让性能上升）。**

**`nompamssa`（MPA 与 MSSA 都删，α=1.5）—— 本次的重点**

| ρ | ρ_win | F1 | P | R | Δ |
|---|---|---|---|---|---|
| 1% | 0.0136 | 0.9506 | 0.9405 | 0.9610 | — |
| 5% | 0.0560 | 0.9474 | 0.9342 | 0.9610 | −0.0032 |
| 10% | 0.1120 | **0.9592** | 0.9500 | 0.9687 | **+0.0118** |
| 20% | 0.2239 | 0.9494 | 0.9380 | 0.9610 | −0.0099 |

> （0.9592 / 0.9494）自己就差 0.0098。

## 4. 为什么两条轴都测不出劣化（四个可量化的原因）

### 4.1 训练侧扰动 + 干净测试 = 测错了问题

两者都只扰动训练集。58k 训练窗口里一半被替换，模型仍能从另一半学到正常模式；
而**评测用的测试集是干净的**。所以测的是"学习鲁棒性"，不是"检测鲁棒性"。
噪声轴上 SMAP/SWaT 的平曲线就是这个原因的直接体现。

### 4.2 模型的异常分数无绝对量纲，检测纯靠排序

`eval_method.py:48`：`thresh = np.percentile(score, float(threshold))` —— 阈值是**百分位**。
实测四种窗口的分数：

| 窗口来源 | 分数 |
|---|---|
| clean train | 48.2937 ± 1.0e-5 |
| clean test | 48.2937 ± 7e-6 |
| **test 真实异常段** | **48.2937 ± 7e-6** |
| test 正常段 | 48.2937 ± 9e-6 |

**真实异常段与正常段的分数分布完全一致。** 根因是 `predict()` 的 VAE 瓶颈
`latent_size=256` 对重构目标 `w_size=275`，**压缩比 1.07 ≈ 无瓶颈**，什么都能重构。

### 4.3 α 无法按可检出性标定

α 从 1.5 放大到 **1000** 倍 σ，注入窗口的检出率只从 0.009 升到 **0.475** 就饱和。
`docs/PRD4text_定量分析_r2.md` §5.4 那个"≥90% 检出"的判据在这个模型上**不可满足**。
→ 污染强度**没有客观锚点**。

### 4.4 异常注入只碰到 1/55 的输入维度

MSL 的 `.npy` 是 27 个通道块纵向拼接，每块**只有第 0 列是信号**，第 1..54 列是二进制的
通道身份指示列（不能动，会破坏通道身份）。所以每次注入影响的是 1/55 的输入维度；
ρ=20% 时真正被扰动的输入占比仅约 **0.36%**。

## 5. 为什么异常之前没加到测试上

两种扰动的原因不同：

- **噪声轴**：继承自 `script/robust/*.sh`（2026-09-08 写的），本来就是"用带噪数据训练"，
  **从来没有测试侧版本**。全仓 `grep add_noise` 只有 `main.py:222` 一处调用。
- **异常轴**：是**刻意**只加训练侧的。PRD4text 的审稿意见原文是
  「需定量说明"**训练集中的异常观测**会干扰正常模式学习"的真实影响」——
  命题本身就是**训练集被污染**。

而且往测试集加异常是**另一件事**：MSL 的测试集本来就有 **36 个真实异常段**，
再往里加合成的，测的是"测试集异常占比更高时检测如何"，属基率/覆盖问题，
不是"正常训练被污染"。

**PRD4text r2 其实知道这个盲区**，并为此加了补偿指标 §8.3 的 `E_A^inj`
（在被注入的**训练段本身**上测重建误差）——因为从干净的测试侧本来就看不见训练侧的注入。
**这个盲区正是两条曲线都平的原因之一（§4.1）。**

## 6. 若要继续，可选方向

| 路 | 说明 | 代价 | 风险 |
|---|---|---|---|
| **A. 接受否定结果** | "该模型对训练集扰动不敏感"是可报的发现，但**不支持"MSSA/MPA 有用"** | 0 | 与论文主张不符 |
| **B. 改扰动到测试侧** | 干净训练 → 含噪/含异常检测。标准鲁棒性协议，模型必然有反应 | 加一个开关 | 需重新定义"抗扰"的语义 |
| **C. 加大 α / ρ** | 直到曲线下降 | 低 | ⚠️ **方法学问题**：强度无客观锚点（§4.3），等于用因变量定自变量 |
| **D. 换评价口径** | 不用阈值型 F1，改用 `E_A^inj`（§8.3）等**在注入段上直接测**的量 | 中 | 指标不常规，需说服审稿人 |

**建议不要在 C 上花时间。** 前三条已证明强度没有客观依据，加大 α/ρ 只会得到一个
"因为调大了所以下降了"的曲线，经不起"你们怎么确定这个强度合理"的一问。
