## 1. 为什么暂停

原计划是「controlled training contamination」：往训练集里注入**结构化异常段**，看检测性能随
污染比例 ρ 如何退化，以此支撑「消融导致劣化、且劣化随污染加重」的假设。

执行过程中查明**三件事**，其中前两件使这条路的重型设计失去支点：

| # | 发现 | 后果 |
|---|---|---|
| 1 | **α（异常强度）无法按可检出性标定** | §5.4 的"调 α 使 clean 模型对注入段 ≥90% 检出"在此模型上**不可满足**：α 放大到 1000 倍 σ，检出率也只到 47.5% 就饱和。整个污染强度的选取失去客观依据 |
| 2 | **模型的异常分数无绝对量纲** | 分数恒定在 48.2937、起伏仅 1e-5；真实异常段与正常段的分数分布**完全一致**。检测纯靠排序（`eval_method.py:48` 用 `np.percentile`） |
| 3 | WADI 不能承担该实验 | 同配置重复运行的 std 是 MSL 的 **13 倍**，且 test 只有 1 个异常段（recall 恒为 1） |

**判断**：要继续做污染实验，就得分段几何、α 标定、通道选择、注入空间这一整套自由参数都给出
交代，而其中 α 这一环已被证明拿不到客观依据。相比之下，「直接改噪声」的自由参数少得多、
已有的 `script/robust` 就是现成实现。**故转向轻量的噪声支撑实验。**

## 3. 三个技术发现（本次的核心资产）

### 3.1 MSL 的数据是「27 个通道堆叠」，不是 55 通道

`MSL_train.npy` 形状 `(58317, 55)`，但它是**逐通道文件纵向拼接**的：27 个通道
（`C-1, C-2, D-14…T-9`）各占一段，**每段第 0 列是信号，第 1..54 列是二值指示列**。
行数对得上：27 × 55 = 58317 ✓（SMAP 同理：53 × 25 = 135183 ✓）。

**后果**：
- "MSL 有 55 个通道"是误导，实际是 **27 条单变量序列**
- 可注入单位是 **(通道块, 第 0 列)**：27 个块中 **22 个可注入**（5 个恒值：`C-2, D-14, M-6, S-2, T-5`）
- 其中 `P-10`(σ=0.0012)、`P-14`(σ=0.0001) 近乎恒定，实际可用约 **20 个**
- 段不能跨块（跨块时信号含义突变），只能改第 0 列（指示列注入 `ασ` 会产生非法状态）
- 完全推翻了 r2 里"段内随机抽 1~3 个**连续通道**"的设计——那个设计对 MSL 无意义

### 3.2 模型的异常分数无绝对量纲，检测纯靠排序

`eval_method.py:48`：`thresh = np.percentile(score, float(threshold))` —— `bf_search` 扫的
93~100 是**百分位**，不是分数。

实测四种窗口的分数：

| 窗口来源 | 分数 |
|---|---|
| clean train | 48.2937 ± 1.0e-5（跨度 5.3e-5） |
| clean test | 48.2937 ± 7e-6 |
| **test 真实异常段** | **48.2937 ± 7e-6** |
| test 正常段 | 48.2937 ± 9e-6 |

**真实异常段与正常段的分数分布完全一致**，F1 只能来自 1e-5 量级的**排序**差异。

**架构根因**：`predict()` 里 VAE 的瓶颈是 `latent_size=256`，重构目标是 `w_size = C·5 = 275`，
**压缩比 1.07 ≈ 无瓶颈**，故几乎能重构任何输入，残差退化成常数。

**论文要用到的地方**：① 必须用**排序类指标（逐点 AUPRC）**报告；② 任何依赖绝对分数幅度的
分析（阈值标定、重构误差分布）在此模型上都不可靠。

### 3.3 WADI 不能承担定量实验

- 同配置重复运行的 F1 std = **0.0972**（MSL 是 0.0075，**13 倍**）
- test 集**只有 1 个异常段**（175 点 / 1.01%），point-adjust 下 recall 恒为 1.0 → F1 退化成
  纯 precision 指标（这解释了上面 0.6542/0.7990/0.9588 那个 0.30 的跨度）
- ρ=1% 档物理上不可表示（train 仅 20,000 时间戳）
- 4 个通道在原始 CSV 里整列 NaN

**可行的效应量级**：要检出 0.01 的差异，WADI 需要 ~20 个 seed（SEM 0.022），MSL 只需 3~5 个
（SEM 0.0033~0.0043）。**这是选 MSL 的定量理由。**

### 3.4 附带查明（与污染实验无关，但影响论文表述）

- **`--batch_size` 对 WADI 曾被静默覆盖**：`ExpConfig` 在 `parse_args` 之后无条件置 24，
  历史最优的 bs=32 无法复现。**已修**（改成只在命令行未显式给时才套默认值）
- **`bf_search` 返回的是百分位**，`metrics.threshold` 不是分数（曾导致标定全 0）
- **`results/ablation/mamba_WADI_seed42.json` 张冠李戴**：是 `1-casestudy` 的 W=140 残留，
  不是 PRD1 的基线。已备份 13 个 JSON 并从备份恢复

## 6. 下一步：转向「噪声定量实验」

见 `docs/PRD4_噪声定量实验.md`。核心差异：

| | PRD4text（污染，暂停） | PRD4_噪声（新） |
|---|---|---|
| 扰动对象 | 往训练集**注入结构化异常段** | 按比例**直接替换为噪声** |
| 自由参数 | 段数/段长/通道数/异常类型/α/注入空间 | 噪声比例 + 噪声强度（σ 倍数） |
| 客观依据 | **α 无法标定**（§3.1） | σ 倍数有明确物理含义 |
| 现成实现 | 本次从零写的 4 个脚本 | **`script/robust/*.sh` 已有** |
| 定位 | 重型 motivation 实验 | **轻量支撑实验** |

**要保留的三条**（无论走哪条路都成立）：
1. 用 MSL，不用 WADI（§3.3）
2. 报告排序类指标（§3.2）
3. `add_noise` 的噪声必须**按通道 σ 缩放**，不能用绝对常数 ±2/±5
   （原来那套的问题不是"注入在 preprocess 之后"——§6.1 已证明先后等价——而是
   **±2/±5 是绝对常数，跨通道不可比**）
