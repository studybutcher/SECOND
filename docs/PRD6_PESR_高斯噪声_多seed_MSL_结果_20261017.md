# PRD6 · 主模型在基础高斯加噪下的多 seed 结果（MSL，2026-10-17）

> 依据 `docs/PRD6_PESR_高斯噪声_多seed_MSL.md`。
> 用户 2026-10-17 的决定：**加噪切回最基础版 B（整行替换 `N(0,1)`）**、
> **主模型 PESR（`--backbone mamba`）**、**只跑 MSL**、**只报 F1**、**3 个 seed**。
>
> **两条结论：**
> 1. **F1 对高斯噪声不敏感**：η 从 0 加到 0.5（一半训练行被替换成 `N(0,1)`）,
>    seed 均值从 **0.9467 变到 0.9490**，差 0.0023，**小于 clean 组自身的 seed-sd（0.0136）**。
> 2. **但这不是"模型鲁棒"的证据**：F1 是 point-adjust 的产物（`PRD5.2` 已量化：
>    同一批 run 上 F1 可摆 2.6× 而 AUROC 只摆 0.03）。本轮**没有落分数**，
>    因此无法用 AUROC/AUPRC 复核；结论只能停留在"F1 上无趋势"。

**η 间最大差 0.0076 < clean 组 seed-sd 0.0136** ⇒ 在 F1 口径下，
"50% 训练行被换成 `N(0,1)`"与"换个 seed"不可区分。

> 注：这一轮 η=0 组**没有加噪**，其 sd（F1 0.0136 / P 0.0283 / R 0.0090）
> 是**纯训练随机性**的估计；其余各档的 sd 是"噪声实现 + 训练随机性"的合并方差
> （`set_seed` 在 `add_noise` 之前，见 PRD6 §1.3）。两者量级相同，
> 说明噪声实现本身没有贡献可测的额外方差。

## 3. 与 PRD5.2（LSTM-AE）并排

| 维度 | PRD5.2（LSTM-AE） | 本轮（PESR） | 可比？ |
|---|---|---|---|
| η 档 | {0, .05, .10, .15, .2, .5} | **同** | ✔ |
| seed | 42 / 7 / 17 | **同** | ✔ |
| 评测 | bf_search + point-adjust | **同** | ✔ |
| 加噪 | 混合噪声（U/±5/walk） | **基础高斯 N(0,1)** | ✘ |
| 指标 | F1 + AUROC/AUPRC | **仅 F1** | 部分 |
| 数据集 | MSL | MSL | ✔ |

**可并排读的只有"形状"：**

- PRD5.2：F1 无趋势（0.42–0.68，组内 sd 0.17–0.23），AUROC 无趋势（0.587–0.595）。
- 本轮：F1 无趋势（0.941–0.949，组内 sd 0.002–0.014）。

**不能并排读"绝对高低"**：两轮加噪分布不同、指标口径不同，而且两者的"平"
来源可能相反 —— PRD5.2 §3.2 指出 PESR 的分数层接近常量（未调整 AUROC≈0.4975），
F1 平可能是**塌缩 + point-adjust** 造成的伪平；LSTM-AE 的平是分数有结构但噪声确实
没影响。**本轮没有 `--score-dump`，无法在这 18 个 run 上验证是哪一种。**

## 4. 判据（PRD6 §6）

| # | 判据 | 结果 | 说明 |
|---|---|---|---|
| **D1** | 18 个 JSON 齐全；同 η 下 3 个 seed 的 F1 不全部相同 | **✔ 通过** | 18/18，`noise_kind` 全为 `gauss`，params 全为 201.6167 M |
| **D2** | 报告每 η 的 seed-sd；若 sd 与 η 间差同量级，则不能声称"噪声导致退化" | **✔ 报告，✘ 不能声称退化** | η 间最大差 0.0076 < clean sd 0.0136 |
| **D3** | 与 PRD5.2 形状一致 | **✔ 形状一致（都平）** | 但来源可能不同，见 §3 |
| **D4** | clean mean 落在既有 clean 值（F1≈0.9577）的 seed 波动内 | **✔ 通过（边缘）** | 0.9467 vs 0.9577，差 0.0110 ≈ 0.81 × 0.0136；注意既有值来自 W=140 的另一批 run，比较本身较松 |

> **可以写**：在 `N(0,1)` 整行替换、η ≤ 0.5 这套协议下，PESR 的 point-adjust F1
> 没有随 η 下降（0.947 → 0.949，差异在 seed 波动内）。
> **不能写**：模型鲁棒；也不能说"加噪没有影响" —— F1 在这套评测里无分辨力，
> 且本轮未落分数。要支持鲁棒性结论，必须先补 AUROC/AUPRC。

## 5. 边界与未做

- **只跑了 MSL**。其余三集复用同一脚本：`DATA=SMAP bash script/robust/robust_multiseed.sh`
  （成本约 4–6 h/集，视机器负载）。
- **F1-only**（用户决定）。`main.py` 已有 `--score-dump`，补 AUROC/AUPRC 不必重训以外的改动，
  但需重跑 18 个 run（约 4.2 h）。
- **sd 是合并方差**：seed 同时改变噪声实现与训练随机性。要分离，需固定噪声索引
  （PRD6 §6 的可选控制组），本轮未做。
- **η=0 组无噪声**，其 F1 0.9467 与论文 robust 表 MSL clean 的 0.9577（W=140）
  并不完全同协议，§4 D4 的比较只能算松校验。
- **val ⊂ test** 的既存缺陷沿用未改，所有 η 同病，不影响"无趋势"结论。
