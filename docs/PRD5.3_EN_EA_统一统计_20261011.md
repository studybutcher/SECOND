# PRD5.3 · AE 与 LSTM-AE 的 E_N / E_A / E_A−E_N 统一统计（2026-10-11）

> 把两轮实验（`PRD5.1_r3` 的 AE、`PRD5.2` 的 LSTM-AE）放在同一套定义下统计。
> **两轮的扰动族不同**，所以是两张并排子表，不是同一条曲线。

---

## 0. 定义（必须统一，否则不可比）

| 量 | 定义 |
|---|---|
| **E_N** | 测试集中**正常窗**的逐元素 MSE（held-out、干净） |
| **E_A** | 测试集中**异常窗**的逐元素 MSE |
| **E_A − E_N** | 绝对差距（**量纲随各自归一化，跨模型不可比**） |
| **E_A / E_N** | 无量纲 ⇒ **唯一可跨模型比较的量** |
| 标签 | any-in-window（两轮一致） |
| 窗口 | 逐实体切（不跨 MSL stacked 接缝），test 按 `main.py` 的 35% 截断 |
| 归一化 | **各模型用自己的**：AE 用 train-fitted scaler；LSTM-AE 走 `utils.get_data`（train/test **各自**拟合，本仓/OmniAnomaly 的历史口径） |

⚠️ **E_N 用哪个"正常集"会改变比值水平**：AE 的 val_normal（train 文件里实体的后段）
MSE = 0.000884，而 test-normal MSE = 0.001152（**+30%**）。两者都是"正常"，但来自不同时间段。
本文统一用 **test-normal**（因为 LSTM-AE 的 `main.py` 里**没有干净 val** —— 它的 val 取自 test 尾部且含异常）。
换成 val-normal 时 AE 的比值是 **1.68**（不是 1.29），但**对污染的不变性两种定义下都成立**。

## 3. 三个观察

### 3.1 **`E_A/E_N` 在污染下几乎是常数**

- AE：**1.2911 – 1.2941**，四档总跨度 **0.0030**（±0.12%）
- LSTM-AE：**1.1034 – 1.1100**，六档总跨度 **0.0066**（±0.30%）

**两种扰动族、两个模型、10 个污染档，比值都没动。** 而且没有单调趋势（AE 的 ρ=20% 略高、
LSTM-AE 的 η=20/50% 略低，都在 seed 噪声内）。

> 这比 `ΔE_N` 干净得多：`ΔE_N` 要除以每 seed 的 E_N，而 E_N 的**跨 seed 离散度**（AE ±17%、
> LSTM-AE ±15%）本身就大于污染效应；比值把每 seed 的尺度**自归一化**掉了。

### 3.2 比值对"训练质量离群"也稳健

AE 的 ρ=5% 那一档，E_N 因 1/24 个未收敛 run 被抬高 **+22%**（0.000884 → 0.001410），
**但比值仍是 1.2911（vs 基准 1.2917）** —— 因为 E_N 与 E_A 一起被抬高，比值不变。

⇒ `E_A/E_N` 同时免疫**污染**和**训练波动**，是个比 E_N 稳得多的量。
代价：它只回答"异常相对正常差多少倍"，不回答"绝对重建质量如何"。

### 3.3 两个模型的**判别余量**差 2.6 倍（跨模型唯一可比的量）

| 模型 | E_A/E_N | 超出 1 的部分 | 独立证据 |
|---|---|---|---|
| **AE** | 1.292 | **0.292** | — |
| **LSTM-AE** | 1.106 | **0.106** | 未调整 AUROC 0.587–0.605 |

AE 的"异常比正常差"的余量是 LSTM-AE 的 **2.8 倍**。两者都是弱检测器，
但 AE 在这一点上明显更强。**这属于模型本身的差别，不是污染的差别。**

---

## 4. 判据

| 判据 | 结果 |
|---|---|
| 污染使 `E_A/E_N` 上升/下降 | **✗** 两族都没动（≤0.6%，无趋势） |
| 污染使 `E_A − E_N` 变化 | **✗** AE 0.00033→0.00033；LSTM-AE 0.00057→0.00060 |
| 污染使 `E_N` 上升 | **✗** AE 已单独证过（`PRD5.1_r3_AE结果` §4，D2 命中） |

**可以写**：在两种训练侧扰动族（结构化异常段注入 α=1.5σ ρ≤20%；整行 ±2/±5 噪声 η≤50%）下，
**"异常相对正常的重建差距"这个比值保持不变**（1.291±0.002 / 1.106±0.003）。
**不能写**：训练污染无害。
